# 용어 및 표기 규약 (Glossary)

## 1. 표기 원칙

- 한글 표준 표기를 기본으로 하고, 각 장에서 최초 1회만 영문을 병기한 뒤 이후 생략한다.
  예: 핸드오프(handoff) → 이후 "핸드오프"
- 제품명·기술명은 영문 원문을 유지한다. — Chatwoot, Groq, FastAPI, Docker, PostgreSQL, Redis
- 코드 식별자는 백틱과 원문을 유지한다. — `setUser()`, `conversation_id`
- 번역이 어색한 용어는 음차 표기를 유지한다. — 웹훅, 핸드오프, 인텐트, 페이로드
- 문장 주체를 생략하지 않는다. 특히 구현 주체가 Chatwoot인지, 본 실습인지 드러나도록 쓴다.
- 동사는 기여 등급에 맞춰 고정한다.

## 2. 행위자 및 구성요소

| 표준 표기       | 영문 / 코드        | 정의                                                                      | 금지 표기                             |
| --------------- | ------------------ | ------------------------------------------------------------------------- | ------------------------------------- |
| 방문자          | visitor            | 상담을 요청하는 웹 사용자. 게스트와 회원을 모두 포함하는 상위 개념        | 고객, 사용자, 유저, 클라이언트        |
| 게스트          | guest              | 로그인하지 않은 상태의 방문자                                             | 비회원, 익명 사용자, 미인증 사용자    |
| 회원            | member             | 데모 홈페이지에 로그인한 방문자                                           | 가입자, 인증 사용자                   |
| 상담사          | agent              | 상담사 콘솔에서 방문자에 응대하는 사람                                    | 상담원, 운영자, 관리자, 오퍼레이터    |
| 상담사 콘솔     | —                  | Chatwoot가 기본 제공하는 상담사용 웹 UI. 대기열·응대·이력 조회 수행       | 관리자 모듈, 대시보드, 상담사 앱      |
| 상담 위젯       | —                  | 웹 페이지에 삽입되는 Chatwoot 방문자용 채팅 UI                            | 채팅창, 챗봇 창, 상담창               |
| 데모 홈페이지   | chatdesk           | 위젯 삽입 및 로그인/회원가입을 제공하는 자체 구현 웹 애플리케이션         | 테스트 사이트, 프론트엔드             |
| AI 서버         | chatdesk-ai-server | 웹훅을 수신해 인텐트를 분류하고 봇 응답을 생성하는 자체 구현 FastAPI 서버 | 봇 서버, AI 엔진, 챗봇 서버, LLM 서버 |
| 봇              | bot                | AI 서버가 생성한 자동 응답의 주체                                         | 챗봇, AI, 에이전트                    |
| 대화            | conversation       | Chatwoot가 관리하는 상담 단위. 방문자 1명과 상담사/봇 간의 메시지 묶음    | 세션, 채팅방, 스레드, 티켓            |
| 턴              | turn               | TODO: 방문자 발화 1회 + 봇 응답 1회를 1턴으로 정의할지 확정               | 메시지, 왕복                          |
| 웹훅            | webhook            | Chatwoot가 AI 서버로 이벤트를 전달하는 HTTP 콜백                          | 훅, 콜백 URL                          |
| 컨텍스트 윈도우 | context window     | LLM 호출 시 함께 전달하는 직전 대화 이력의 범위                           | 히스토리, 대화 기록                   |

## 3. 인텐트 분류

프로젝트에 LLM 기반 다중 카테고리 분류기는 없음. 실제로 존재하는 분류 로직은 두 갈래이며 성격이 다르므로 표를 나눔.

### 3-1. 문의유형 (위젯 버튼 선택, `app/services/prompts.py:46-51`)

방문자가 위젯 인사 직후 버튼(input_select)으로 직접 고르는 값. LLM 분류가 아니라 사용자 선택이며, 선택값은 `conversation_state.set_inquiry_type`(`app/services/conversation_state.py:32-34`)에 저장되어 이후 LLM 메시지에 주입됨(`app/routers/webhook.py:180-183`).

| 표준 표기 | 코드값        | 정의                            | 판정 기준                        |
| --------- | ------------- | ------------------------------- | -------------------------------- |
| 제품 문의 | `"제품 문의"` | 제품 스펙·기능 관련 질문        | 방문자가 버튼 클릭으로 직접 선택 |
| 주문·배송 | `"주문·배송"` | 주문 상태, 배송 조회 관련 문의  | 방문자가 버튼 클릭으로 직접 선택 |
| 환불·교환 | `"환불·교환"` | 환불/교환 절차 문의             | 방문자가 버튼 클릭으로 직접 선택 |
| 기술 지원 | `"기술 지원"` | 사용 중 오류, 설정 등 기술 문의 | 방문자가 버튼 클릭으로 직접 선택 |
| 기타 문의 | `"기타 문의"` | 위 4종에 해당하지 않는 문의     | 방문자가 버튼 클릭으로 직접 선택 |

### 3-2. 핸드오프 트리거 판단 (`app/services/handoff_rules.py:32-54`)

메시지 키워드 매칭 기반으로 AI 응답 대신 사람 상담사에게 넘길지 판단. 애매한 경우 LLM(`confirm_intent`, `app/services/llm_client.py:47-62`)로 재확인.

| 표준 표기           | 코드값(`rule.name`) | 정의                                    | 판정 기준                                                                                                                                   |
| ------------------- | ------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 보안/결제           | `security`          | 결제·계정 보안 관련, 긴급 처리 필요     | `strong_patterns` 키워드(결제, 이중 결제, 환불, 해킹, 도용, 계정 해킹, 계정 탈취, 개인정보, 비밀번호) 포함 시 즉시 매칭 → 우선순위 `urgent` |
| 상담원 연결         | `connection`        | 사람 상담원과의 연결을 원하는 의도      | "연결" 포함 시 즉시 매칭. "상담원/상담사/사람/직원" 등 애매한 키워드만 있으면 LLM에 재확인(예: "상담사 자격증"은 제외) 후 매칭              |
| 기타(핸드오프 없음) | —                   | 위 3종에 해당하지 않는 문의, 인사, 잡담 | 위 규칙 모두 미매칭 → AI가 직접 응답                                                                                                        |
